# 圆景记录 iOS 开发版 0.2

SwiftUI 主应用、WidgetKit 快捷入口和 XCTest 界面测试。最低 iOS 17，当前开发使用 Xcode 26.3，iOS 26.3.1 模拟器。

## 运行与签名

打开 `Yuanjing.xcodeproj`，选 `Yuanjing` Scheme 和 iPhone 模拟器运行。实体手机需要在应用和小组件两个 target 选择自己的开发 Team、唯一 Bundle Identifier，并连接已信任 Mac 的 iPhone。未签名构建产物不能直接安装到实体手机。

## 验证命令

从仓库根目录执行：

```sh
ios/Tests/run.sh

# 可选：用本机导出文件进行读取、导入、备份恢复、重复导入核对
# 不会改写原文件，也不会将真实账单写进仓库。
ios/Tests/run.sh '/path/to/export.csv'

# 使用本机实际可用的模拟器名称或 id
xcodebuild -project ios/Yuanjing.xcodeproj -scheme Yuanjing \
  -destination 'platform=iOS Simulator,name=iPhone 15 Pro' \
  -derivedDataPath /tmp/yuanjing-tests CODE_SIGNING_ALLOWED=NO test
```

UI 测试使用独立 UUID 数据目录，不清空日常记录。Debug 构建支持 `--test-store UUID` 测试参数，Release 不启用。

## 数据规则

- 金额为 Int64 整数分；债务账户按负值参与总余额。
- 本地文件位于 Application Support/Yuanjing/records.json，原子写入。写入失败保留原状态，加载失败停止覆盖并允许从有效备份恢复。
- 导入支持 UTF-16 BOM Tab 文本及 UTF-8 CSV / TSV，包括带币种符号、分组逗号的金额和带引号的多行备注。当前导入类型为支出／收入，未知类型整批拒绝。
- 源日期按 Asia/Shanghai 解释；保留全部七个原始字段，明确的小类按 U+2010 分隔符拆分。备注不自动转为标签。
- 行字段指纹加同内容出现序号用于重复识别：重复导出不会重复记账，同一文件中两条完全相同的真实记录仍保留。
- 历史导入不影响当前余额。预览确认文件覆盖完整日期区间后，才扩展同期统计的历史覆盖范围。
- 修改本应用新记的账单时调整账户余额差额；已被之后余额校准覆盖的历史影响不再重放。修改导入记录只调整统计。有关联回款时，金额不能低于累计回款。
- 回款按实际到账日期影响净支出，原消费详情保留关联退款与分摊。待收不算资产。
- 备份恢复校验版本、账户引用、唯一编号、金额、日期及回款关系。恢复前另存本地副本；这些副本当前没有自动清理策略。
- 通知需用户在设置启用并授权。以计时起点／最近排便为提醒锚点，成功安排后持久化标记，防止普通记账或重启导致同一次过期提醒反复通知。新记录重新计算间隔。

## 已验证与限制

- 原生应用与 Widget 扩展可编译；iPhone 15 Pro 模拟器已正常启动。
- 领域测试覆盖金额、转账、校准、回款、周期比较、导入、恢复、重复识别、提醒策略和账单编辑。
- XCTest 已跑通新建标签与记账、退出重开后的账单保留、排便计时重启恢复以及结束保存。
- 完整本机旧导出已通过解析和数量／金额核对；未将个人账单植入分发版本。
- 通知实际送达、Files 选取／导出恢复、小组件在桌面上的交互，仍需补充系统级和真机验证。

5. 图片附件、更多分类自定义、账单删除或归档与导入批次撤销。
6. 正式应用图标、无障碍、大字体及更多设备尺寸验证，原生涂鸦细节精修。
