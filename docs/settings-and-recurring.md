# 设置与固定收支

设置作为独立底栏页面，与记账、便便、睡眠并列。账户与记账、固定收支与快捷记录、便便与提醒、数据管理分别归组。首页每个导航入口独立成行，避免多个 NavigationLink 在一个 List 行内一起触发。

固定收支支持收入和支出、金额、账户、大类、小标签、首次日期，以及每周／每月／每年重复。到期只展示待确认，不预先改余额；每次确认当前一期，按到期日生成账单。跳过和暂停不产生资金变动。编辑只影响尚未确认的安排，删除安排保留已生成账单。删除已生成账单不会自动重新生成该期。恢复暂停后，旧的待处理期继续显示，不静默跳过。

以最初日期为周期锚点，月末遇到短月采用月底，之后回到原定日。相同期次重复确认会被拒绝。固定收支和处理进度包含在 JSON 备份中；旧备份没有该字段时仍可恢复。

## 快捷指令研究

用户提供的页面展示的是懒猫存钱「自动记账」入口，明确显示通过快捷指令绑定轻点背面或辅助触控触发；截图未展示快捷指令内部动作，不能据此断言其金额识别或数据上传实现。

Apple 官方说明支持通过轻点背面运行快捷指令：
https://support.apple.com/zh-cn/guide/shortcuts/apd897693606/ios

圆景目前在「快捷记账」页提供已存在的 `yuanjing://expense` URL 配置步骤。此入口只打开记账表单，不宣称已支持支付截图识别或读取其他应用账单。进一步核实对方实现需要快捷指令分享链接或动作列表。
