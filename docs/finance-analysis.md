# 账本分析与设置宫格

设置是独立底部页面，按「账本分析」「账户与记账」「便便与提醒」「数据管理」分组。每项以图标宫格入口呈现，返回一级即回设置。

- 金额分析：净支出、收入、期间结余、日均净支出、已过天数、账单笔数，以及支出/收入趋势。当前发薪周期显示对前三个周期相同已过天数平均花费的百分比。
- 大类分析：环形占比、金额排序、笔数、账单明细。
- 标签分析：大类与小标签组合分别统计；同名标签不会跨大类合并。支持搜索标签、筛选大类和查看明细，未填标签也保留统计。
- 日期范围：薪月（默认，读取发薪日）、周（周一开始）、自然月、自然年、自选首尾日期。自然周期可前后翻页；日期范围含结束日全天。
- 收入仅含收入；净支出为支出减退款及分摊回款。回款按到账日期统计，归属于原支出的当前分类与标签，即使原支出不在查询区间。转账和余额校准不计入收支。
- 期间结余不等于账户余额；日均分母为范围内已经过去的自然日（含今天），未来范围显示横杠。图表不补未来零值；超过 93 天按月汇总，其余按日。
- 净额为负的分类单列；占比分母为正净额分类的合计。环图显示前 8 项，其余合并；列表保留所有项。

## 待用户准备最新账单后迁移

分析与布局更新不会自动导入个人账单。迁移时用最新完整导出预览核对日期范围、金额、账户对应和标签字段；检查手机测试记录与导出记录是否重叠，再确认导入。导入历史不会重放扣款。最后逐项校准账户余额和欠款，并导出备份，从该余额继续日常记账。
