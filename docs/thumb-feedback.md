# 拇指操作与真实账本使用反馈

- 记一笔和修改账单复用 EntryForm，修改保留原编号、退款关联和历史导入元数据。
- 收入采用独立分类列表，默认含二手、工资、奖金、红包、礼金、副业、中奖、投资、股票、租金、其他收入；设置内可分别管理收入与支出分类，移除入口不删除历史。
- 标签输入使用稳定的 UIKit UITextField，输入法存在 markedText 时不回写文本。键盘 Done / 右侧「标签完成」先结束标签输入，然后右下角「完成」记账。标签弹层的「选择」位于下方右侧。
- 进入记账页触发轻触感反馈，数字键播放系统按键声。保存过程有重复提交保护。
- 退款可一键填入整单剩余可退金额，扣除已退金额及分摊回款，仍经 Ledger 校验后确认记账。
- 首页账单按自然日分组，显示每日收入、净支出；退款和分摊冲减支出，转账不计入。
- 便便开始/结束按钮与表单保存位于底部右侧。一般图标改为 24 点高，移除多余状态行；血迹、沾马桶使用紧凑选择项，保持可点击区域。

历史数据合并在本地独立执行：写入前备份、读取最新账本、验证原记录和余额不变，写入后回读核对。个人备份和转换结果不进入公开仓库。
