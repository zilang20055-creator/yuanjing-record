# 历史数据迁移与记录交互

状态：账单预览导入、重复识别、原字段保留及备份恢复已在原生开发版实现，并通过本机完整导出的内存往返测试。本文同时保留尚待实现的截图迁移、批次撤销及归类目标；尚未在实体手机正式迁入个人数据。

## 记账导出

样本虽然以 .csv 结尾，实际是带 BOM 的 UTF-16 LE 文本，列分隔符是 Tab。应检测编码与分隔符，使用标准 CSV 解析器，不能只按扩展名选择逗号解析。

| 原字段 | 导入字段 | 处理方式 |
| --- | --- | --- |
| 日期 | occurredAt | 保留到分钟；源文件无时区，不凭空添加秒级精度；导入时明确时区 |
| 分类 | originalCategory、categoryId、subcategoryId | 保留原文；明确的父子分类分隔符为 U+2010「‐」，通过映射预览确认拆分 |
| 类型 | kind | 样本含支出、收入；不能据此断言源应用没有转账功能 |
| 金额 | amountMinor、currency | 样本使用 ¥；金额按十进制解析为整数分，币种在导入预览中确认 |
| 账户 | sourceAccount | 保留原账户，首页仍突出总余额 |
| 账本 | sourceLedger | 保留来源账本，可筛选，不要求增加日常操作步骤 |
| 备注 | note | 原文保留；店名或用途可以映射为小分类，也可直接筛选统计 |

### 小分类与店名

- 旧备注包含店名、用途及自由文本，不能全部直接当成小分类。
- 导入预览展示高频备注候选、对应大类、记录数，让用户按规则批量归类。
- 已有明确小分类时保留该层级；需要按店名统计时可以直接筛选备注，避免被迫改成三级分类。
- 同义大类保持原值，提供显式合并映射；不自动把不同名称当成同一类。
- 日常记账界面：金额键盘、大类、小类、完成同页可达；常用小类优先，备注为独立可选项。

### 退款、转账和余额

- 备注包含「退款」的旧收入只标成待核对候选，保留原类型，不能自动关联一笔金额相近的消费。
- 旧导出缺少原交易标识和退款关联关系；不能保证自动重建历史退款链。
- 自有账户转账不影响总余额；历史记录只有确认语义后才改为转账。
- 信用卡、花呗记录保留来源。未来若记录还款，需要区分原消费与偿还负债，避免重复计入消费。
- 历史收支差额不是当前总余额。采用用户设置的余额基准和生效时间，基准前账单仅用于历史统计。

### 导入检查

- 预览记录数、日期范围、按类型合计、分类映射、异常行和重复候选。
- 金额用整数分或 Decimal 计算；不使用二进制浮点作为账目存储。
- 导入前后按记录数、类型、年度核对合计；保留原始字段和源行号以便追溯。
- 完全相同的文件通过文件指纹避免重复导入；重叠导出按行内容与出现次数检查候选，不能直接删除所有相同行，因为可能存在真实的重复消费。
- 导入需支持批次撤销；没有明确源交易 ID 时，不声称可以无误自动去重。

## 排便截图

### 可恢复范围

- 月历：可识别显示月份、有记录的日期及部分图标；未选中日期的次数和详情不可推断。
- 选中日期下方列表：可读取可见记录的时间、时长、颜色、形态、地点；有多条记录时可能需要滚动。
- 详情页：可读取完整选择项；滚动截图需确认来自同一条记录。
- 编辑页展示的内容不等于已保存记录，导入草稿需保留这一来源状态。
- 日期级记录与详情记录分开表达完整度；日期级记录不能被当作「这天只有一次」。后补详情时替换或关联该日期占位，不能重复累加。
- 日历空白表示截图没有显示记录，不等于确认未排便；未来日期不纳入历史。
- 保留无法确定的字段为未知，不从邻近日、默认项或常用项推测。

### 详情选项与交互

截图补充了腹部感受和备注两个字段。首版包含：日期、时长、形态、颜色、分量、排便感觉、气味、厕纸血迹、是否粘马桶、腹部感受、心情、地点、备注。

- 分量：非常少、少量、一般、大量。源界面的重量提示是选项描述，不视为实测重量。
- 排便感觉：轻松、困难、意犹未尽。
- 血迹：无、有；默认无。源界面指「厕纸有没有血」，不扩展成已检查所有形式的出血。
- 粘马桶：不粘、粘；默认不粘。
- 地点：家、学校、公司、公厕，支持自定义。
- 形态、颜色、气味、腹部感受和心情均使用图示加文字点选；截图只显示部分选项的说明，未展示的语义不能只凭图标猜测。
- 高频选项优先展示，默认项由用户设置；可以一屏核对常用选择，其余详情展开。
- 保留日期和时长编辑；短至数秒的源记录原样保留，不擅自改成分钟。
- 原应用图标和健康分数不直接复用；分数算法未知，不能自创等价分数。

### 小组件

- 排便小组件：距上次排便的天／小时／分钟，以及开始入口；已有未结束记录时返回该次计时，避免新建重复记录。
- 记账小组件：记一笔入口，并可显示最近一笔；另提供周花销趋势组件。
- 只有日期、没有时间的历史记录不伪装为精确到分钟的「距上次」数据。
