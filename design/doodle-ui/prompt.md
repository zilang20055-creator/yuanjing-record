# UI 图集提示词

生成方式：内置 image_gen；输入 1522.PNG 作为风格参考，不是待修改图片。

Use case: ui-mockup asset sheet. Create ONE production UI sprite atlas for the personal iPhone app 圆景记录. Attached image is a STYLE REFERENCE: relaxed cute doodle black blob-cat, very thick rounded uneven BLACK outlines, charcoal-gray flat fills, pink accents, deliberately goofy asymmetrical face, hand-drawn rather than polished corporate icons. Translate that visual language into an original cohesive functional icon family. 
Canvas: square 1024x1024, pure solid white background, no paper texture, no gradients, no shadows, NO TEXT, NO LETTERS, NO NUMBERS, no dividers, no grid lines. EXACTLY 25 isolated pictures arranged in exactly 5 equal columns and 5 equal rows. Each cell occupies exactly 20% of canvas width and height. Each picture is centered in its cell and fits in central 70% of that cell leaving clear empty margins. All cells same scale. Intended to be used directly as CSS background sprite regions, precise alignment is essential.
Read left to right top to bottom:
Row 1: bowl of rice with pink chopsticks (food); chunky shopping bag with pink heart (shopping); cute little front-facing bus (transport); cup with straw and pink drink (beverage); smartphone with tiny heart (digital consumption).
Row 2: toy robot head with silly eyes (models); hand-soap pump bottle (daily necessities); telephone handset with little sound marks (communication); dumbbell (sport); admission ticket with pink star (entertainment).
Row 3: video game controller (games); two clinking glasses with pink drink (social); desktop computer (electronics); small house with pink roof (housing); pawprint (pets).
Row 4: travel suitcase (travel); loose t-shirt with pink heart (clothes); rounded scissors (beauty); shipping parcel (delivery); simple first aid kit (medical).
Row 5: open wallet and coin (finance navigation); chunky toilet with closed cute eye expression (bowel navigation); a sleepy curled charcoal black blob-cat with pink cheek (sleep navigation); same silly original blob-cat hugging a large pink coin with no lettering (balance hero mascot); same silly original blob-cat giving a pink heart a hug (empty state and completion mascot).
A few accents pale mint and butter yellow permitted, but mostly black outlines, charcoal, white and blush pink. Silhouettes instantly recognizable at 32–48 pixels. No human body, no realistic stool. Absolutely no caption, logos or watermark. Preserve reference's loose endearing handmade energy.
