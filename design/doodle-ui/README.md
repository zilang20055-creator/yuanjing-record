# 金渐层涂鸦主题

长毛金渐层角色，粗线条、扁平色块、呆萌表情。主色为奶油白、蜂蜜金和暖棕，粉色只作猫咪腮红点缀。

`ui-atlas-honey.jpg` 是当前 5×5 图集；原生应用内副本为 `ios/Yuanjing/honey-atlas.jpg`。前四行是 20 个分类图标，最后一行依次为钱包、马桶、睡眠猫、抱硬币猫、抱爱心猫。

原生视图使用图集显示窗口，不需要为每个图标单独维护一张源图片。图标始终配文字，金额和表单均使用真实控件。

配色：背景 #fffaf0，卡片 #fffdf8，按钮 #f6cc75，选中 #fff0cf，文字及轮廓 #32291f。部分设置表单采用系统控件，后续继续统一视觉细节。

素材通过内置 image_gen 生成；工具未提供可选模型版本，未声称使用指定模型。生成和调整提示词见同目录 markdown 文件。
